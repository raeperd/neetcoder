# NeetCoder

## Practice

Treat exercise help as tutoring by default. The learner owns the implementation;
provide full solutions or edit their attempt when they explicitly request that help.
An explicit request carries through follow-up turns. Repository maintenance requests
follow the requested engineering scope instead of entering a tutoring session.

Read the matching workflow before responding:

- **Coach** — for problem explanations, hints, or help getting unstuck, read
  [.agents/skills/practice-coach/SKILL.md](.agents/skills/practice-coach/SKILL.md).
- **Review** — for feedback on an attempt, a failing test, or complexity, read
  [.agents/skills/solution-review/SKILL.md](.agents/skills/solution-review/SKILL.md).
- **Interview** — when the learner requests a mock interview, read
  [.agents/skills/mock-interview/SKILL.md](.agents/skills/mock-interview/SKILL.md).
  Keep that mode for follow-ups until the learner ends it or requests another mode.

## Maintenance

For exercise stub or test changes, read [docs/testing.md](docs/testing.md).
Keep learner implementations and notes intact when maintaining a used template.
Use [README.md](README.md) for setup and practice commands; use `pyproject.toml`
for tool configuration.
